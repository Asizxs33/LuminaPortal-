# LuminaPortal для Windows

Лёгкое приложение на Tauri 2 (Rust + TypeScript), использующее системный WebView2. Интерфейс и шрифты работают без внешних загрузок. Сайт и исходная Python-программа не заменяются.

## Использование

1. В кабинете администратора/преподавателя у собственного теста нажмите «Бағдарламаға жүктеу». Файл `.lumina-test` содержит все языковые версии группы и настройки случайной выборки, времени и проходного балла.
2. Установите LuminaPortal, откройте файл, выберите язык, укажите имя и почту своего ученического аккаунта.
3. Начните тест. Ответы и отметки сохраняются на диске после каждого изменения. После перезапуска нажмите «Продолжить тест». Закрытие программы не останавливает таймер.
4. После завершения отправьте результат из программы, войдя в свой аккаунт. Пароль и токен не сохраняются. Для переноса через флешку сохраните `.lumina-result` и загрузите его на странице своих результатов на сайте.
5. Повторная попытка получает новый UUID; прежние результаты остаются в истории. Повторная отправка одного UUID не создаёт дубль.

В программе выбор «Локальный сайт» подключается к `http://127.0.0.1:4189`, основной сайт — к `https://luminaportal-edu.vercel.app`. Обновлённый сервер должен быть развёрнут до использования отправки в основной сайт.

## Ограничения первой версии

- Поддерживаются текстовые вопросы с одним правильным вариантом. Экспорт отклоняет банк с кодом, изображениями, пустыми вопросами или неоднозначным ключом. Сайт продолжает поддерживать эти тесты.
- Файл предназначен для автономной работы и содержит ключ ответов. Подпись проверяется сервером при загрузке результата; интерфейс приложения не выдаёт проверку подписи при открытии за подтверждение подлинности.
- Сервер пересчитывает балл по подписанному снимку вопросов, не доверяя присланному баллу. Подпись действует 180 дней; смена серверного JWT_SECRET делает старые файлы непригодными для загрузки результатов.
- Автономный таймер использует часы компьютера; случайная выборка и условия прохождения не подтверждаются сервером. Такие результаты обозначаются `desktop_offline`, отдельно от контролируемого экзамена. Извлечение ключа или подделку ответов/локальных данных на управляемом учеником компьютере это не предотвращает.
- История хранится в `%APPDATA%/edu.lumina.desktop/state.json` и предыдущей копии. Ошибка записи показывается пользователю. Сохранения ограничены 24 МБ; крупные банки увеличивают размер истории. Перед очисткой устройства экспортируйте результаты.
- Установщик загружает WebView2 только при его отсутствии. Поэтому установка на компьютер без WebView2 впервые требует интернета. Сама программа с уже установленным WebView2 работает без интернета.
- Сборка не подписана сертификатом издателя; автоматическое обновление не включено.

## Разработка и сборка

Windows 10/11 x64, Node.js, Rust stable MSVC, Visual C++ Build Tools и Windows SDK.

```powershell
cd D:/LuminaPortal-/desktop
npm ci
npm test
npm run build
npm run tauri -- dev
npm run build:windows
npm run package:windows
```

Порт предпросмотра: 4192. В браузерном предпросмотре сохранения идут в localStorage; сетевую отправку выполняет только установленное приложение. Rust разрешает только два фиксированных API-действия (вход и отправка) к указанным выше адресам, без перенаправлений. Права доступа к произвольным файлам и выполнение команд оболочки не предоставляются интерфейсу.

Выходные файлы: `src-tauri/target/release/lumina-desktop.exe` и `src-tauri/target/release/bundle/nsis/LuminaPortal_0.1.0_x64-setup.exe`.

## Сервер

Примените добавочную миграцию `node server/scripts/migrate-desktop.cjs`. Она добавляет `results.source` со значением `web` для прежних строк; попытки не удаляются.

Проверки: `node node_modules/tsx/dist/cli.mjs server/scripts/check-desktop.ts` создаёт изолированные данные `@example.invalid`, проверяет права, подписи, пересчёт балла, отдельные пересдачи и повторную отправку, затем удаляет только свои записи. Не запускайте проверки одновременно с резервным копированием, если в копию не должны попадать временные QA-записи.
