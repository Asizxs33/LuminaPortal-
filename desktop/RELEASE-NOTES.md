# 0.1.0 — 2026-11-05

Первая Windows x64 сборка: выбор языковой версии, случайные вопросы и варианты, таймер, навигация, отметки, полноэкранный режим, сохранение незавершённой попытки, история пересдач, экспорт результата и отправка в свой аккаунт.

Сервер: подписанные экспорты только для владельца/администратора; проверка подписи и пересчёт балла; отдельный источник `desktop_offline`; идемпотентная загрузка. Предыдущие результаты сохранены.

Проверено: 8 проверок модели, 20 интеграционных проверок на изолированных данных с очисткой, 28 проверок анонимных/поддельных запросов, TypeScript фронтенда и затронутого backend, Expo web export, Windows release/NSIS build. В окне Windows проверены загрузка двуязычного файла, выбор языка, ответ, полноэкранный режим, восстановление начатой попытки после перезапуска. В браузерном интерфейсе проверены навигация, отметки, завершение по таймеру, повторная попытка и итог 2/2.

Ограничения и инструкция — в README.md. Основной сайт требует развёртывания обновлений; локальная БД уже получила добавочную миграцию `results.source`. Настоящий пароль пользователя и реальные ученические попытки при проверке не использовались.
